
# backend-SQL

A simple backend web application built with **Node.js, Express.js, and MySQL** for managing user information.

## Features

* View all users from the MySQL database
* Display user ID
* Display username
* Display email
* Display password
* Update a user's username
* Connect and interact with a MySQL database through Express

## Tech Stack

* **Node.js** — Backend runtime
* **Express.js** — Web framework
* **MySQL** — Database
* **EJS** — Server-side templating
* **HTML/CSS** — Frontend


## How It Works

The application uses **Express.js** to handle requests and **MySQL** to store user information.

Users can be displayed from the database, and the username of an existing user can be updated through the application.

## Installation

Clone the repository:

```bash
git clone <your-github-repo-link>
```

Go into the project folder:

```bash
cd backend-sql
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node index.js
```

Then open the local server in your browser.

## Database

The project uses MySQL to store user information.

Example user fields:

```text
id
username
email
password
```
